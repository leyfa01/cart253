# Don't press the Button

Leyna Feknous

[View this project online](https://leyfa01.github.io/cart253/topics/prototypes/conditions/condition-prototype-3/)

## Description

This prototype is a button that reacts differently each time it is clicked. The messages, background, and button movement change as the player keeps pressing it.
