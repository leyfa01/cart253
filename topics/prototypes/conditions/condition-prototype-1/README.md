# Feed the panda

Leyna Feknous

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

This interactive prototype lets you feed a panda with bamboo using the mouse. The panda becomes happy when the bamboo is close and angry when it moves away.
