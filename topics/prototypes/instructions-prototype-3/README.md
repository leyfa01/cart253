# Mood Bot - weird prototype

Leyna Feknous

[View this project online](https://leyfa01.github.io/cart253/topics/prototypes/instructions-prototype-3/)

## Description

This prototype is a robot created with 3D shapes to represent different emotions, including happy, sad, neutral, and angry. Each expression is created by changing the robot’s eyes, eyebrows, mouth, colors, and rotations.
