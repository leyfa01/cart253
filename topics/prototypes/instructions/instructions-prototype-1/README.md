# The Solar System - representational prototype

Leyna Feknous

[View this project online](index.html)

## Description

This prototype represents a simple solar system made with 2D shapes and different colors. The planets and the Sun are created using basic geometric shapes. There are no controls; the goal is to create a simple visual representation of space while experimenting with size, position, and color.
