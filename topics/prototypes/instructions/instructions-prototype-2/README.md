# Geometric Chaos - abstract prototype

Leyna Feknous

[View this project online](https://leyfa01.github.io/cart253/topics/prototypes/instructions/instructions-prototype-2/)

## Description

This prototype is an exploration of 2D and 3D geometric shapes using different sizes, colors, layers, and rotations. It includes shapes such as circles, rectangles, a sphere, a torus, and a Bézier curve. The user can use the mouse to move around the 3D scene and view the shapes from different angles.
